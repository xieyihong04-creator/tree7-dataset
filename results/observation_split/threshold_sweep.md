# 選擇性預測門檻（grouped valid 選、grouped test 驗證）

> 部署值：**TTA + 0.85**（valid 選出）。`demo/app.js`、`demo/config.json` 與 `guard_consistency.md` 都使用同一個 0.85；0.80 只作為覆蓋率較高的替代方案。

規則：門檻在 valid 上選「covered accuracy ≥ 99% 的最低 t」，再原封不動套到 test。
信心 = softmax 最大值；TTA = center + 左上/右上/左下/右下共 5 個 224 crop 的平均 logits。
